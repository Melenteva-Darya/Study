# Проект "Виджет банковских операций клиента"

## Описание:

Проект "Виджет банковских операций клиента" - это веб-приложение на Python, которое умеет обрабатывать информацию как о
картах, так и о счетах.

## Установка:

Клонируйте репозиторий:

```
git clone https://github.com/Melenteva-Darya/Study.git
```

## Использование:

```
В модуле widget.py под функцией mask_account_card вставить строку ниже и запустить

print(mask_account_card(payment_method)) 

payment_method - может быть не только счет или номер карты, может быть с названием счета или карты.
```

## Пример работы виджета:

#### Пример для карты

Visa Platinum 7000792289606361 # входной аргумент
Visa Platinum 7000 79** **** 6361 # выход функции

#### Пример для счета

Счет 73654108430135874305 # входной аргумент
Счет **4305 # выход функции
