# Проект "Виджет банковских операций клиента"

## Описание:

Проект "Виджет банковских операций клиента" - это веб-приложение на Python, которое умеет обрабатывать информацию как о
картах, так и о счетах.

## Установка:

1. Клонируйте репозиторий:

```
git clone https://github.com/Melenteva-Darya/Study.git
```

2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```

3. **Активируйте виртуальное окружение:**
    - На Windows:
      ```bash
      venv\Scripts\activate
      ```
    - На macOS/Linux:
      ```bash
      source venv/bin/activate
      ```

4. **Установите зависимости:**

```
pip install -r requirements.txt

```

В модуле widget.py под функцией mask_account_card вставить строку ниже и запустить

print(mask_account_card(payment_method))

payment_method - может быть не только счет или номер карты, может быть с названием счета или карты.

## Пример работы виджета:

```
Пример для карты
Visa Platinum 7000792289606361 # входной аргумент
Visa Platinum 7000 79** **** 6361 # выход функции

Пример для счета
Счет 73654108430135874305 # входной аргумент
Счет **4305 # выход функции
```

## Тестирование и качество кода

Вся бизнес-логика проекта (модули `masks`, `widget`, `processing`) полностью покрыта тестами с использованием фреймворка
`pytest`. Также в проекте настроена строгая проверка типов `mypy` в соответствии с PEP8.

### Команды для запуска проверок:

1. **Запуск тестов и просмотр покрытия (Coverage):**
   ```
   poetry run pytest
   ```
   *После запуска в терминале отобразится таблица с процентом покрытия каждой функции.*

2. **Строгая проверка типов данных:**
   ```
   poetry run mypy src tests
   ```
   *Убедитесь, что команда возвращает `Success: no issues found` перед отправкой кода на проверку.*

3. **Проверка стиля кода (Линтеры):**
   ```
   poetry run flake8 src tests
   ```
