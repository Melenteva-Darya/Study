# Проект "Виджет банковских операций клиента"

## Описание:

Проект "Виджет банковских операций клиента" - это веб-приложение на Python, которое умеет обрабатывать информацию как о
картах, так и о счетах. Создает инструменты для эффективной работы с большими объемами данных транзакций, используя
возможности Python для обработки данных через генераторы. Эти генераторы позволяют финансовым аналитикам быстро и
удобно находить нужную информацию о транзакциях и проводить анализ данных.

## 📊 Работа с CSV- и Excel-файлами

В проект добавлен отдельный модуль для поддержки новых форматов данных:

* **Чтение CSV-файлов**:
    * Реализована функция для считывания финансовых операций, которая принимает путь к файлу CSV в качестве аргумента.
    * На выходе выдает готовый список словарей с транзакциями.
* **Чтение Excel-файлов**:
    * Реализована функция для считывания финансовых операций, которая принимает путь к файлу Excel в качестве аргумента.
    * Также выдает структурированный список словарей с транзакциями.

> 📦 **Обратите внимание**: Все необходимые для работы модуля библиотеки (такие как `pandas`) уже добавлены в зависимости
> проекта.

## Модуль декораторов (`src/decorators.py`)

В проект добавлен модуль `decorators`, который содержит инструменты для автоматического логирования работы функций.

### Декоратор `@log`

Декоратор `@log` автоматически отслеживает начало, завершение работы функции, фиксирует возвращаемые результаты или
возникшие ошибки.

**Параметры:**

* `filename` (необязательный): Строка с путем к файлу логов.
* Если указан (например, `@log(filename="mylog.txt")`), логи дописываются в этот файл.
* Если не указан (`@log()`), логи выводятся прямо в консоль (`sys.stdout`).

#### Примеры использования

1 **Запись логов в файл при успешном выполнении:**

```python
from src.decorators import log


@log(filename="mylog.txt")
def my_function(x, y):
    return x + y


my_function(1, 2)
# В файл mylog.txt запишется: my_function ok
```

2 **Вывод логов в консоль при возникновении ошибки:**

```python
from src.decorators import log


@log()
def divide(x, y):
    return x / y

# При вызове divide(1, 0) в консоль выведется:
# divide error: ZeroDivisionError. Inputs: (1, 0), {}
```
